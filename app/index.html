L'application, à manipuler

Une web app : elle s'ouvre dans le navigateur d'un téléphone et s'ajoute à l'écran d'accueil comme une application, sans passer par un store.

  1. Faites défiler le fil des commerces.
  2. Ouvrez une fiche, puis le catalogue.
  3. Commandez : une référence s'affiche.
  4. Passez dans l'espace commerçant pour préparer la commande.

Commerces, prix et commandes sont fictifs. Rien n'est envoyé : tout reste dans ce navigateur.
